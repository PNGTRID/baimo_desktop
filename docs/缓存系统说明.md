# 数据缓存系统使用说明

## 概述

为了优化页面切换性能,避免重复加载数据,系统实现了全局数据缓存机制。

## 架构

```
┌─────────────────┐
│   页面组件      │
│  (Customers,    │
│   Orders, etc)  │
└────────┬────────┘
         │ 使用
         ▼
┌─────────────────┐
│  useDataCache   │  ← 自定义 Hook
│   Hooks          │
└────────┬────────┘
         │ 管理
         ▼
┌─────────────────┐
│  Zustand Store  │  ← 全局状态
│  (useStore)     │
└─────────────────┘
```

## 核心组件

### 1. Zustand Store (`src/store/useStore.ts`)

**数据结构:**
```typescript
dataCache: {
  customers: Customer[];      // 客户数据缓存
  patterns: Pattern[];        // 图案数据缓存
  orders: Order[];            // 订单数据缓存
  lastUpdate: {               // 最后更新时间戳
    customers: number;
    patterns: number;
    orders: number;
  };
}
```

**核心方法:**
- `setCustomers(customers)` - 更新客户缓存
- `setPatterns(patterns)` - 更新图案缓存
- `setOrders(orders)` - 更新订单缓存
- `invalidateCache(type)` - 使缓存失效
- `isCacheValid(type, maxAge)` - 检查缓存是否有效

### 2. 数据缓存 Hooks (`src/hooks/useDataCache.ts`)

**通用 Hook:**
```typescript
useDataCache<T>(type, loader, maxAge)
// 返回: [data, loading, error, refresh]
```

**专用 Hooks:**
```typescript
useCustomersCache()  // 客户数据
usePatternsCache()   // 图案数据
useOrdersCache()     // 订单数据
```

## 使用示例

### 基础用法

```typescript
import { useCustomersCache } from '@/hooks/useDataCache';

function Customers() {
  const [customers, loading, error, refresh] = useCustomersCache();

  // customers: Customer[] - 客户数据数组
  // loading: boolean - 加载状态
  // error: string | null - 错误信息
  // refresh: () => Promise<void> - 手动刷新函数

  return (
    <div>
      <Button onClick={refresh} loading={loading}>
        刷新
      </Button>
      {error && <Alert message={error} type="error" />}
      <Table dataSource={customers} loading={loading} />
    </div>
  );
}
```

### 数据变更后刷新缓存

```typescript
// 创建客户
const handleCreate = async (values) => {
  await CustomerApi.create(values);

  // 刷新缓存
  await refresh();
};

// 更新客户
const handleUpdate = async (id, values) => {
  await CustomerApi.update({ id, ...values });

  // 刷新缓存
  await refresh();
};

// 删除客户
const handleDelete = async (id) => {
  await CustomerApi.delete(id);

  // 刷新缓存
  await refresh();
};
```

## 缓存策略

### 缓存有效期

- **默认**: 5 分钟 (300,000 毫秒)
- **自定义**: 可在调用时传入 `maxAge` 参数

```typescript
// 默认 5 分钟
const [data, ...] = useDataCache('customers', loader);

// 自定义 10 分钟
const [data, ...] = useDataCache('customers', loader, 10 * 60 * 1000);
```

### 缓存判断逻辑

```typescript
isCacheValid(type, maxAge) {
  const lastUpdate = dataCache.lastUpdate[type];
  const data = dataCache[type];

  return data.length > 0 && Date.now() - lastUpdate < maxAge;
}
```

## 性能优化

### 1. 页面切换优化

**问题**: 每次切换页面都重新加载数据
**解决**: 使用缓存,只在缓存过期或手动刷新时加载

```typescript
// ❌ 旧方式 - 每次都加载
useEffect(() => {
  loadCustomers();
}, []);

// ✅ 新方式 - 自动使用缓存
const [customers, loading] = useCustomersCache();
```

### 2. 并行加载

订单页面同时需要订单和客户数据:

```typescript
const [orders, ordersLoading, ordersError, refreshOrders] = useOrdersCache();
const [customers, customersLoading, customersError] = useCustomersCache();
const loading = ordersLoading || customersLoading;
```

两个请求会并行执行,且自动使用缓存。

### 3. 缓存失效

某些场景需要手动使缓存失效:

```typescript
const { invalidateCache } = useStore();

// 使所有缓存失效
invalidateCache('all');

// 使特定缓存失效
invalidateCache('customers');
invalidateCache('patterns');
invalidateCache('orders');
```

## 最佳实践

### ✅ 推荐做法

1. **使用专用 Hooks**
   ```typescript
   const [customers, loading, error, refresh] = useCustomersCache();
   ```

2. **数据变更后刷新**
   ```typescript
   await CustomerApi.create(values);
   await refresh(); // 确保数据最新
   ```

3. **统一错误处理**
   ```typescript
   useEffect(() => {
     if (error) message.error(error);
   }, [error]);
   ```

### ❌ 避免做法

1. **不要混用本地状态和缓存**
   ```typescript
   // ❌ 错误
   const [customers, loading] = useCustomersCache();
   const [localCustomers, setLocalCustomers] = useState([]);

   // ✅ 正确 - 直接使用缓存
   const [customers, loading] = useCustomersCache();
   ```

2. **不要手动操作缓存数据**
   ```typescript
   // ❌ 错误
   customers.push(newCustomer);

   // ✅ 正确 - 通过 API 更新后刷新
   await CustomerApi.create(values);
   await refresh();
   ```

## 未来扩展

### 持久化缓存

目前缓存仅保存在内存中,刷新页面会清空。未来可以考虑:

1. **IndexedDB 持久化**
   - 适合大量数据
   - 支持离线使用

2. **LocalStorage 持久化**
   - 适合少量数据
   - 简单易用

3. **版本化缓存**
   - 数据库 schema 变更时自动清理旧缓存

### 更细粒度的缓存

```typescript
// 按客户 ID 缓存订单
useCustomerOrdersCache(customerId);

// 按日期缓存订单
useDailyOrdersCache(date);
```

## 总结

数据缓存系统通过 Zustand Store 和自定义 Hooks 实现了:

- ✅ 页面切换无需重新加载
- ✅ 自动管理缓存有效期
- ✅ 简单易用的 API
- ✅ 统一的错误处理
- ✅ 并行数据加载

显著提升了应用性能和用户体验。
